探索 SnakeLauncher 的功能

从版本扫描到实时通信，从反作弊到自更新，覆盖游戏管理链路上的每一个环节。

双分支统一管理

C# WPF 版与 Python 版同台管理，自动识别 5 种目录布局，智能解析版本号并自动去重。

了解详细信息

500ms 级实时通信

通过 Named Pipe 与游戏建立低延迟双向通道，FPS、得分、击杀数持续上报，状态栏实时渲染。

了解详细信息

纵深反作弊体系

静态完整性校验、HMAC 签名验证、行为合理性检测，三层防护。告警不中断游戏进程。

了解详细信息

一键完成的自更新

独立 Updater 进程无锁更新，覆盖前备份到时间戳目录，任何失败自动从备份还原。

了解详细信息
实时通信

与游戏，实时同步。

通过 Named Pipe 建立低延迟双向通信通道，游戏内发生的一切都能被启动器感知。FPS、得分、击杀数、模式状态持续上报，无需切换窗口即可查看。

安全防线

三层防护，固若金汤。

无缝更新

一次点击，焕然一新。

更新流程被拆分为可观测、可中断、可恢复的独立阶段。独立 Updater 进程从临时目录运行，不锁定安装目录。任何一步失败，已覆盖的文件都会自动从备份还原。
